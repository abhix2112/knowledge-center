Install software only from **Company Portal**. Apps there are licensed, security-checked and updated automatically.

## Install an app

1. Open **Company Portal**.
2. Search for the app and click **Install**.
3. It installs in the background. You don't need admin rights.

## The app you need isn't there

Request it in the Service Portal under **Request software**. Include the app's name, website and what you need it for. Security reviews new software within 5 business days. Paid software also needs your manager's approval.

## Why not download from the internet?

Downloaded installers are the most common way malware gets onto company laptops. Laptops block installers that aren't signed by approved publishers, so they usually fail anyway.

Developers have extra options; see *Developer laptop setup: Python and uv*.
